# 🚀 Quotation System - Quick Start Guide

## 🎯 In 30 Seconds

**NEW QUOTATION**
1. Click "New Quotation" button
2. Select customer (lead) from dropdown
3. Select package (optional but recommended)
4. Add any extra services
5. Review pricing breakdown
6. Set payment terms
7. Click "Create Quotation"

✅ **Done!** Your quotation is created.

---

## 📋 The 5 Steps Explained Simply

### STEP 1️⃣: Who Is This For?
- **Action**: Click lead search box
- **Search**: Type customer name/ID/email
- **Select**: Click customer from list
- **Result**: Customer info auto-fills ✅

### STEP 2️⃣: What Package?
- **Action**: Click package search box
- **Search**: Type package name or destination
- **Select**: Click package from list
- **Result**: Price and details auto-fill ✅

### STEP 3️⃣: Any Extras?
- **Action**: Click "+ Add Service" button
- **Choose**: Category (🏨Hotel, 🚗Flight, 🎯Activity, etc.)
- **Enter**: Description, Quantity, Unit Price
- **Result**: Total price calculates automatically ✅
- **Repeat**: Add more services as needed

### STEP 4️⃣: Check the Price
- **Subtotal**: Sum of all services
- **Discount**: If any
- **Tax**: Automatic calculation
- **TOTAL**: Final amount in big bold text
- **Action**: Verify it looks correct

### STEP 5️⃣: Payment Terms
- **Tax Rate**: Set to 10% (or your rate)
- **Discount**: Add if needed
- **Payment Terms**: Choose from dropdown
- **Terms & Conditions**: Add any special terms
- **Status**: Set to Draft or Sent
- **Notes**: Add internal notes for team

**CLICK "CREATE QUOTATION"** ✅

## ❓ Quick Help

**Q: I can't find a customer**
A: The customer must be added to Leads first. Ask admin to create the lead.

**Q: What if I made a mistake?**
A: Edit the quotation before sending. After sending, create a new version.

**Q: Can I add a discount?**
A: Yes! In Step 4 settings, choose "Percentage" or "Fixed Amount"

**Q: What does "Valid Until" mean?**
A: Date when quotation expires (usually 30 days)

**Q: Can I send this to the customer?**
A: Yes! Change status to "Sent" and the system will handle it.

## 🔄 What Happens After?

**After Creating Quotation:**
1. Quotation saved in system ✅
2. Gets unique quotation number (QT-YYYYMM-00001)
3. Can be edited (if not yet sent)
4. Can be converted to invoice (if accepted)
5. Can be sent to customer
6. Tracked until completion

## 📊 Quotation Statuses

| Status | Meaning |
|--------|---------|
| Draft | Still working on it |
| Sent | Sent to customer, waiting for response |
| Accepted | Customer approved, ready to bill |
| Rejected | Customer declined |
| Expired | Validity period passed |
| Converted | Became an invoice |
