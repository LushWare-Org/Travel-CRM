## 📋 Project Overview

**Trip Sky Way** is a comprehensive travel agency management system with:

- **Customer Portal**: Package browsing, booking, and account management
- **Admin Dashboard**: Lead management, itinerary creation, and analytics
- **Backend API**: RESTful API with authentication, payments, and notifications

### Technology Stack
- **Runtime**: Node.js 18+
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT with refresh tokens
- **Payments**: Stripe & Razorpay integration
- **File Storage**: Cloudinary
- **Email/SMS**: Nodemailer & Twilio
