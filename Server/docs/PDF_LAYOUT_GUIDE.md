## 🎨 Design Features

### Color Scheme
- **Brand Color**: `#1E40AF` (Blue) - Headers, brand name
- **Secondary Color**: `#64748B` (Gray) - Body text
- **Accent Color**: `#F59E0B` (Amber) - Decorative lines
- **Success**: `#10B981` (Green) - Inclusions
- **Error**: `#EF4444` (Red) - Exclusions, Emergency

### Typography
- **Headers**: Helvetica-Bold, 20-32pt
- **Body Text**: Helvetica, 10-12pt
- **Subheaders**: Helvetica-Bold, 12-16pt

### Interactive Elements (Clickable Links)
✅ **Email Links**: `mailto:info@tripskyway.com`
✅ **Phone Links**: `tel:+919876543210`
✅ **Website Links**: `https://www.tripskyway.com`
✅ **WhatsApp Links**: `https://wa.me/919876543210`
✅ **Social Media**: All platform links

### Page Layout
- **Margins**: 50px all sides
- **Page Size**: A4 (595 x 842 points)
- **Footer**: 780px from top (reserved on all pages)
- **Content Width**: 495px

### Visual Elements
- 📧 Email icon (emoji)
- 📞 Phone icon (emoji)
- 🌐 Website icon (emoji)
- 📍 Location icon (emoji)
- 🏨 Accommodation icon (emoji)
- 🍽️ Meals icon (emoji)
- 🚗 Transport icon (emoji)
- 💬 WhatsApp icon (emoji)
- 🚨 Emergency icon (emoji)
- ✓ Checkmark for inclusions/activities
- ✗ Cross for exclusions

### Information Boxes
- **White boxes** with colored borders for key information
- **Light gray boxes** (`#F8FAFC`) for accommodation/meals
- **Red box** (`#FEF2F2`) for emergency contact
